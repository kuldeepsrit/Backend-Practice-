# 🔐 Authentication Project

A full authentication system built using React , Node.js and JWT . 

## 🚀 Tech Stack

- Frontend: React (Vite)
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT

## 📂 Project Structure
Authentication/
 ├── backend/
 ├── frontend/

## ⚙ Installation

### 1️⃣ Clone the repository

git clone https://github.com/kuldeepsrit/Backend-Practice-.git

### 2️⃣ Install Backend

cd backend
npm install
npm start

### 3️⃣ Install Frontend

cd frontend
npm install
npm run dev

## 🔑 Environment Variables
Inside -  `.env` file inside backend and add:

JWT_SECRE
MONGO_URI
